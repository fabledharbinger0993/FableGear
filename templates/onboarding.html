May FableGear scan your drives?
This looks across all connected drives and volumes for music-specific files: Rekordbox databases (master.db), playlist XML exports, Pioneer USB structures, and audio library folders. It reads file names and locations only — nothing is opened, copied, or modified, and nothing leaves this Mac.

May FableGear read your Rekordbox database?

Reading the database lets FableGear see what tracks are in your library, where their files are, and whether any paths are broken. Nothing is modified at this stage.

⚠️
Full Disk Access may be required macOS restricts reading files in protected folders like ~/Library. If FableGear can't read your database, grant Full Disk Access to Terminal (or FableGear) in System Settings → Privacy & Security → Full Disk Access.
Tools unlocked with read access
▣Library AuditMaps your full library, flags broken paths and orphaned entries
🏷Tag TracksCross-references the database when prioritising files for analysis
🔎Find DuplicatesUses DB metadata for smart pre-filtering before fingerprinting
✏️

May FableGear write to your Rekordbox database?

Some tools make changes to your library. FableGear always creates a timestamped database backup before any write operation, and Rekordbox must be closed first.

Tools unlocked with write access
📍Fix Broken PathsUpdates file paths in the database after a drive rename or move
＋Import TracksAdds new audio files to your Rekordbox library
🔗Link PlaylistsAssociates imported tracks to playlists based on folder structure
✂Prune DuplicatesRemoves confirmed duplicates from the database and optionally the disk
Backup guarantee
Every write operation creates a timestamped copy of your database before it touches anything. Backups are stored in FableGear Archive/Savepoints beside your chosen library (or inside a custom archive, if you set one later). Rekordbox must be closed before FableGear will attempt a write.
🤖

AI integration

FableGear can run a local MCP server so AI copilots (Claude Code, Claude Desktop, Cursor) can drive your tools — audit, tag, dedupe, organize — from a conversation. It listens on localhost only and is off by default. You can change this any time in Settings.

What an AI copilot can do once connected
🩺Audit & reportRun library health checks and read the results back to you
⚙️Run tools with your rulesEvery safety gate still applies — dry-runs, backups, Rekordbox-closed checks
📜Read job historyCheckpoints and past runs from the FableGear archive
