            Folders with these names are skipped during all scans (Tag Tracks, Normalize, Convert, Audit). Use this to exclude nested drive copies, app data, or any non-music folder inside your music root.
          

        


        

          
Features affected when logging is disabled

          

            Tag Tracks → Duplicate Finder: Tag Tracks normally writes a scan index so the Duplicate Finder can skip files that clearly aren't duplicates. Without it, every file gets fingerprinted every run. On a 10,000+ track library this is the difference between minutes and hours.
          

          

            Rollback unavailable: Import, Normalize, Relocate, and Prune make changes that cannot be undone without Savepoints. There is no recovery if something goes wrong.
          

          

            Triage limited: Problem files from scans can be Revealed in Finder or sent to Trash, but cannot be moved to Quarantine — that folder won't exist.
          

          

            Duplicate reports: CSV reports require a manual destination path each run — there is no default location to save them to.

      FableGo is the iPhone companion to FableGear. Queue downloads, browse your library, manage playlists, and export to Pioneer drives — all from your phone.
    

    

      It installs as a web app (PWA) — no App Store or native build tools required. Just open it in Safari and tap Add to Home Screen.
    

    
What you need

    
    
      
  • Your iPhone on the same Wi-Fi as this Mac — or Tailscale for remote access
    • 
      
  • Safari on iPhone (required for Add to Home Screen)
    • 
      
  • Optionally: Tailscale on both devices for access from anywhere
    • 
    

    

      LAN only? If both devices are on the same Wi-Fi, Tailscale is optional — LAN access works out of the box. Tailscale gives you remote access from anywhere.
    

  


  
  

    

      Install Tailscale on this Mac so your iPhone can reach FableGear remotely.
    

    

      
tailscale.com/download/macos

  • Sign in with Google, Microsoft, or GitHub
    • 
      
  • Click Connect in the Tailscale menu bar icon
    • 
    

    

      Already installed? Make sure the menu bar icon shows Connected before moving on.
