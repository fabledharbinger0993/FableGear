Log & Archive Destination

          


            

            

            

          


          

            
Features affected when logging is disabled

            

              Tag Tracks → Duplicate Finder: Without a scan index, every file gets fingerprinted every run.
            

            

              Rollback unavailable: Import, Normalize, Relocate, and Prune changes cannot be undone without Savepoints.
            

            

              Triage limited: Problem files cannot be moved to Quarantine.
            

            

              Duplicate reports: CSV reports require a manual destination path each run.
            

          

        

      


      
      

        

          
AI Agent Access (MCP)

          
Run a local MCP server so AI agents (Claude, Cursor, etc.) can manage your library through natural conversation. Everything stays on your machine.

          

        

      


      
      

        

          
Tool Definitions

          

            Tag Tracks — Scans audio files with librosa for BPM and key detection. Writes ID3/Vorbis tags. Optional MusicBrainz enrichment fills in missing title, artist, and album.
          

          

            Rename — Cleans filenames by standardizing separators, removing junk characters, and applying artist/title formatting rules. Dry-run mode previews all changes first.
          

          

            Convert — Converts between audio formats (FLAC, WAV, AIFF, MP3, AAC) via FFmpeg. Preserves all metadata tags during conversion.
          

          

            Normalize — Adjusts loudness to a target LUFS using FFmpeg loudnorm. Previews before/after levels. Does not alter dynamic range.
          

          

            Organize — Sorts files into a clean folder structure (Artist/Album or Genre/Artist) based on embedded tags. Moves or copies, never deletes.
          

          

            Duplicates — Fingerprints audio content (not just filenames) to find true duplicates. Groups matches by acoustic similarity. You choose which to keep.
          

          

            Novelty — Scans external drives for tracks not in your main library. Finds unique music across multiple sources.
          


          
Concepts

          

            Record Room — Library browser with database and filesystem views. Build playlists, preview tracks, and export to Rekordbox.
          

          

            Chop Shop — File maintenance workspace. Every tool that touches files lives here: tag, rename, convert, normalize, organize, dedupe, import, link, and path repair.
          

          

            Archive — Automatic logging: savepoints (DB snapshots before writes), quarantine (problem files), and CSV reports. Lives beside your library or wherever you point it.
          

          

            MCP Server — Model Context Protocol endpoint that lets AI coding assistants control FableGear tools via structured API calls. Runs on localhost:5002.

AI Agent Access

      

      

        FableGear can run a local MCP server so AI agents (Claude, Cursor, and others)
        can manage your library on your behalf — auditing, tagging, organizing, and importing
        tracks through natural conversation.
      

      

        

          Local & private — the server runs on your machine. Nothing leaves localhost unless you choose to expose it.
        

        

          You stay in control — every write operation still requires Rekordbox to be closed and creates an automatic backup.
        

        

          Works with any MCP client — Claude Desktop, Claude Code, Cursor, Windsurf, and more.

      FableGo is the iPhone companion to FableGear. Queue downloads, browse your library, manage playlists, and export to Pioneer drives — all from your phone.
    

    

      It installs as a web app (PWA) — no App Store or native build tools required. Just open it in Safari and tap Add to Home Screen.
    

    
What you need

    
    
      
  • Your iPhone on the same Wi-Fi as this Mac — or Tailscale for remote access
    • 
      
  • Safari on iPhone (required for Add to Home Screen)
    • 
      
  • Optionally: Tailscale on both devices for access from anywhere
    • 
    

    

      LAN only? If both devices are on the same Wi-Fi, Tailscale is optional — LAN access works out of the box. Tailscale gives you remote access from anywhere.
