# FableGear optional dependencies — installed BEST-EFFORT.
#
# Nothing here may be required for the app to run. setup.sh, launch.sh and the
# install wizard install this file with failures tolerated, so a package that
# has no wheel for the user's platform degrades a feature instead of breaking
# the install.
#
# This file is intentionally empty of analysis libraries. Audio analysis is
# FableGear's own: Iron (iron/) finds BPM, key and beat positions, Anvil
# (anvil/) reads and writes tags, Quench (quench/) levels loudness on ffmpeg.
#
# essentia (AGPL-3.0) was listed here until v1.2.0 as a best-effort BPM
# fallback. It is gone: FableGear is for-sale software and a copyleft runtime
# dependency is a commercial risk, Iron measured better than it on real
# Rekordbox ground truth (docs/IRON_RESEARCH.md §25), and its wheel coverage
# meant most installs never had it anyway. Do not re-add it.
